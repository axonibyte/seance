# THE PROMOTION RULE
#
# Any seed that ever finds a defect is appended to this file permanently, with
# a comment naming what it found and the commit that fixed it. It is never
# removed -- not when the defect is fixed, not when the run gets slow, not
# when somebody is sure it is now redundant. A seed that found something once
# is the only kind of seed with a proven track record, and the battery is the
# cheapest possible guard against that exact defect returning.
#
# Hunting runs (SEANCE_HUNT=1) draw fresh seeds from /dev/urandom and print
# each one before using it; when one fails, copy the printed seed here.
#
# Appending a seed is not a decision that needs anyone's permission. Removing
# one is, and the answer is no.
